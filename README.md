# Simulation Engineering Toolkit 01 — Rust for Simulation Engineers

Why Rust suits discrete-event simulators, taught through a real kernel: a BinaryHeap event list with SimPy's tie-breaking, events as enums, ownership in an event loop (arenas and indices, not references), SimPy processes as explicit state machines, traits for cost models, error handling, rayon sweeps, and the cargo, clippy, rustfmt, proptest and criterion toolchain.

Topics: Ownership, BinaryHeap, Enums & traits, rayon, clippy, proptest, criterion.
